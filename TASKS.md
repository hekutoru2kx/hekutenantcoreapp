- [x] **Moved `BootstrapAdminEmail` out of `appsettings.json` into user-secrets** — the key in `backend/Hekutenantcoreapp.Api/appsettings.json` held a real personal email in a tracked, non-gitignored file. Set it via `dotnet user-secrets set "BootstrapAdminEmail" "<email>" --project backend/Hekutenantcoreapp.Api` and blanked the default to `""` in `appsettings.json` (same pattern already used for `Jwt:Key`, `SmtpUser`, `SmtpPassword`). `Program.cs` already skips break-glass recovery when the value is empty (`string.IsNullOrEmpty(bootstrapEmail) ? null : ...`), so a blank default is safe. The address stays in git history — this only stops further exposure. Applied to gestamind in the same pass; ludemia and hekucoreapp not touched this pass.
- [x] **Renamed `backend/Hekutenantcoreapp.Infrastructure/Respositories/` → `Repositories/`** — the folder name was misspelled while the namespace declared inside the files already read `Hekutenantcoreapp.Infrastructure.Repositories`. Pure `git mv` folder rename, no code change (SDK-style csproj globs `.cs`); backend build clean afterward. Applied to gestamind in the same pass; ludemia and hekucoreapp not touched this pass.
- [x] **Fixed submenu misalignment in nested nav menus** — the System menu's Platform/Identity submenus (and the user menu's Identity & Organization submenu) popped up well above the row that opened them, with a gap the mouse would fall out of before reaching them. Root cause: Material's `mat-menu` nudges a submenu vertically by its parent menu's first-item `offsetTop`, as a correction for the parent panel's own inner padding — a heuristic that breaks once the parent has non-item content above its first item, which this nav's `.user-info` header block always does. Added `shared/submenu-align.directive.ts` (`appSubmenuAlign`, applied to each submenu-triggering button) which cancels just that erroneous vertical offset after the submenu opens and caps its height with scroll as a fallback for tight viewports. Ported from the same fix in ludemia, where it was verified in the browser via a scripted Playwright check (measured trigger vs. submenu panel coordinates before/after).
