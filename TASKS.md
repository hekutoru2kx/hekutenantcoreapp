- [x] **Fixed submenu misalignment in nested nav menus** — the System menu's Platform/Identity submenus (and the user menu's Identity & Organization submenu) popped up well above the row that opened them, with a gap the mouse would fall out of before reaching them. Root cause: Material's `mat-menu` nudges a submenu vertically by its parent menu's first-item `offsetTop`, as a correction for the parent panel's own inner padding — a heuristic that breaks once the parent has non-item content above its first item, which this nav's `.user-info` header block always does. Added `shared/submenu-align.directive.ts` (`appSubmenuAlign`, applied to each submenu-triggering button) which cancels just that erroneous vertical offset after the submenu opens and caps its height with scroll as a fallback for tight viewports. Ported from the same fix in ludemia, where it was verified in the browser via a scripted Playwright check (measured trigger vs. submenu panel coordinates before/after).
